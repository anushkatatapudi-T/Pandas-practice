# Pandas-practice


This repository contains my daily practice exercises as I learn Python Pandas.

## Topics Covered
- Filtering DataFrames
- Grouping data using `groupby()`
- Calculating averages using `mean()`
- Sorting data using `sort_values()`
- Finding maximum values using `idxmax()`
- Selecting rows using `head()`
- Counting values using `value_counts()`

To improve my data manipulation and analysis skills through regular practice.
